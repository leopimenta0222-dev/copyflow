# CopyFlow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** SaaS de geração de conteúdo de marketing com Claude API — login, gerador (6 tipos, tom, idioma, 2–3 variações) e histórico, com a chave protegida num back-end serverless.

**Architecture:** SPA React 19 (Vite). A geração passa por uma função serverless `/api/generate` que guarda a `ANTHROPIC_API_KEY` e chama o `@anthropic-ai/sdk` (modelo claude-sonnet-4-6); sem chave, retorna um **fallback de exemplo** (demo sempre-no-ar). Histórico e auth via Supabase, com **modo demo** (localStorage). Funções `/api` servidas pelo middleware do Vite no dev.

**Tech Stack:** React 19, Vite, Tailwind v4, React Router, TanStack Query, react-hook-form + zod, date-fns, lucide-react, @anthropic-ai/sdk, Supabase. JS.

**Testing:** TDD para o construtor de prompt + parser de variações + config de tipos; verificação da UI/fluxo no navegador (modo demo). **Antes de codar `/api/generate`, ler a skill `claude-api`.**

- [ ] Implementar:
```js
import { getContentType } from './contentTypes'
const TOM = { profissional:'profissional e confiável', descontraido:'descontraído e próximo', persuasivo:'persuasivo e focado em conversão', divertido:'divertido e leve' }
const IDIOMA = { pt:'português do Brasil', en:'inglês', es:'espanhol' }
export function buildMessages({ tipo, contexto, tom='profissional', idioma='pt', n=3 }) {
  const ct = getContentType(tipo)
  const campos = Object.entries(contexto || {}).filter(([,v]) => String(v||'').trim()).map(([k,v]) => `- ${k}: ${v}`).join('\n')
  const system = `Você é um copywriter sênior especialista em marketing e conversão. Escreva em ${IDIOMA[idioma]||IDIOMA.pt}, com tom ${TOM[tom]||TOM.profissional}. ${ct?.promptInstrucao||''} Gere exatamente ${n} variações distintas, prontas para uso. Responda APENAS com um array JSON de strings (sem comentários, sem markdown). Exemplo: ["...","...","..."]`
  const user = `Tipo: ${ct?.label||tipo}\nContexto:\n${campos || '(sem contexto adicional)'}`
  return { system, user, n }
}
export function parseVariations(text, n=3) {
  if (!text) return []
  try { const m = text.match(/\[[\s\S]*\]/); if (m) { const arr = JSON.parse(m[0]); if (Array.isArray(arr)) return arr.map((s)=>String(s).trim()).filter(Boolean).slice(0,n) } } catch { /* ignore */ }
  return text.split(/\n(?:-{3,}|\d+[\).]\s*)/).map((s)=>s.trim()).filter(Boolean).slice(0,n)
}
```

## Phase 2 — Função serverless (Claude)

### Task 2.1: /api/generate + middleware do Vite
**Files:** `api/generate.js`, `vite.config.js`
- [ ] **Antes de escrever:** ler a skill `claude-api` (SDK, modelo, max_tokens, saída estruturada).
- [ ] `api/generate.js`:
```js
import Anthropic from '@anthropic-ai/sdk'
import { buildMessages, parseVariations } from '../src/lib/prompts.js'
import { demoGenerate } from '../src/lib/demoContent.js'
export default async function handler(req, res) {
  if (req.method !== 'POST') return res.status(405).json({ error: 'Método não permitido.' })
  const { tipo, contexto, tom, idioma } = req.body || {}
  if (!tipo) return res.status(400).json({ error: 'Tipo de conteúdo ausente.' })
  const key = process.env.ANTHROPIC_API_KEY
  if (!key) return res.status(200).json({ variacoes: demoGenerate({ tipo, contexto, tom, idioma, n: 3 }), demo: true })
  try {
    const anthropic = new Anthropic({ apiKey: key })
    const { system, user, n } = buildMessages({ tipo, contexto, tom, idioma, n: 3 })
    const msg = await anthropic.messages.create({ model: 'claude-sonnet-4-6', max_tokens: 1024, system, messages: [{ role: 'user', content: user }] })
    const text = (msg.content || []).filter((b) => b.type === 'text').map((b) => b.text).join('\n')
    res.status(200).json({ variacoes: parseVariations(text, n), demo: false })
  } catch (e) {
    res.status(500).json({ error: e?.message || 'Falha ao gerar conteúdo.' })
  }
}
```

## Phase 8 — DB, deploy

### Task 8.1: Migration Supabase
**Files:** `supabase/migrations/0001_schema.sql`
```sql
create extension if not exists pgcrypto;
create table generations (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null references auth.users(id) on delete cascade,
  tipo text not null, input_json jsonb, output_json jsonb,
  idioma text default 'pt', tom text default 'profissional',
  favorito boolean not null default false, criado_em timestamptz not null default now()
);
alter table generations enable row level security;
create policy g_own on generations for all to authenticated using (user_id = auth.uid()) with check (user_id = auth.uid());
create index on generations(user_id, criado_em desc);
```
